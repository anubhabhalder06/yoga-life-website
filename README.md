# Yoga Life Studio Website

Welcome to the official source code repository for **Yoga Life**, a premium Yoga and Zumba studio based in Baruipur, Kolkata.

## About The Project
This website is a fully responsive, modern static web application built purely with HTML, CSS, and JavaScript.
It features a seamless translation system allowing users to toggle between English and Bengali instantly.

## Hosting & Deployment
This project is perfectly optimized for free, zero-config hosting on platforms like **GitHub Pages** or **Netlify**. 
Since there is no build step required, simply serving the root directory as a static site is all that is needed.

## Editing Content
All English and Bengali text is centralized in js/translations.js.
